# v0.2.0 能力对照与验收口径

目标为独立完成日常网页操作。以下能力由 Chrome 操作助手扩展、本机服务和 MCP 实现；实际业务网站的兼容性必须通过对应流程验收，不能仅以存在工具名判定完成。

| 能力 | 实现与验证方式 |
|---|---|
| 网页正文、链接、表格 | 可见结构读取，HTML/ARIA表格，标记已加载范围与截断 |
| 自定义菜单与组件 | DOM与无障碍信息结合；回归覆盖委托事件菜单、开放/封闭组件 |
| 截图 | 可见区域、文档/主滚动区分段、区域、元素；真实 MCP 图片响应及 PNG 文件；元素按需滚动并恢复 |
| 视觉操作 | 原图像素坐标定位；核对缩放、滚动与布局，过期拒绝 |
| 鼠标键盘 | 单/双/右击、悬停、文字输入、组合键、勾选、拖拽、容器滚动 |
| 框架 | 空白框架、srcdoc、同源与跨进程框架；受限目标明确错误 |
| 导航与弹窗 | 前进、后退、刷新、条件等待、普通网页提示与输入框 |
| 标签页 | 按请求接管已有页、跟踪动作产生的新页；结束保留接管页 |
| 文件 | 授权文件控件/选择事件上传；直接链接及网页导出下载关联 |
| 批量 | 100链接、去重、并发3、失败重试、取消、恢复、三种导出 |
| 多任务 | 独立会话、标签归属、文件授权、操作去重、停止传播 |
| 接入 | 本地 stdio MCP；Codex插件，WorkBuddy/Claude接入配置说明 |

开发回归使用仅加载本产品的隔离 Chromium 和真实 MCP 协议。测试框架负责启动浏览器、设置缩放及注入故障；网页操作由本产品工具执行。安装回归验证稳定ID、用户级注册、数据保留、回滚及卸载。

实际测试数量、失败与待验收项以同目录《验收报告》及测试结果JSON为准。Mac两种架构与其他智能体客户端分别登记实机状态；交叉编译成功不代替实机结果。

明确边界：Chrome受保护页面、策略拒绝、登录验证码、跨进程框架之间的拖拽、未加载的无限列表仍需遵守限制。其他智能体需要支持本地 stdio 和 MCP 图片内容。截图不包含浏览器工具栏或操作系统窗口。

屏外元素截图恢复位置后不能用原图坐标点击；返回 coordinateActionReady=false，应使用元素操作或滚动后重截。元素超出可见滚动范围时明确报错。主面板整页截图返回 captureScope 和 contentOffsetY；多个独立滚动区需分别核实，固定页头/侧栏另取可见区域截图。小红书菜单、日期筛选、两页读取、5份导出、概览截图、屏外图表与主滚动面板截图已通过常用 Chrome 的正式 MCP。v2rayN 开启、关闭、恢复及本机服务中断恢复已实测通过。

新任务实测中，小红书首页“发布”链接单击未触发导航，数据看板文字单击未展开。任务通过同一插件的可见 href 导航、最新截图中的展开箭头，完成账号概览读取与截图；这两项入口单击兼容性仍为已知问题，不以目标页面最终到达代替单击测试通过。
